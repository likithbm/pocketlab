
# 🚀 PocketLab — Science Beyond Classrooms

### Interactive STEM Virtual Laboratory | STEM for Impact 2026

PocketLab is an offline-first STEM education platform designed to make practical science and mathematics learning accessible to students, especially those in rural and underserved communities.

## 🎯 Problem Statement

Many schools have limited access to physical laboratories, scientific equipment, and reliable internet connectivity.

PocketLab addresses this problem by providing interactive virtual experiments, animations, quizzes, and student progress tracking in one accessible learning platform.

## ✨ Key Features

- ⚛️ Interactive Physics experiments
- 🧪 Chemistry simulations and Periodic Table Explorer
- 🧬 Biology learning modules
- 🔢 Mathematics visualizations
- 🧠 Quiz Arena with multiple difficulty levels
- 📐 Formulas and real-time experiment readings
- 💬 Built-in offline educational tutor
- 🏆 Quiz scores and student progress tracking
- 📱 Responsive web interface
- 🌐 Offline-first learning experience

## ▶️ How to Run

### Requirements

- Node.js and npm
- Google Chrome or another modern browser

### Installation

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open a terminal inside the backend folder.
4. Install dependencies:

```bash
npm install
```

5. Start the backend:

```bash
npm start
```

6. Open:

http://127.0.0.1:3000

The platform can run locally without internet after all required dependencies are installed.
